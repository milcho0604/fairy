# PR #40 v2: 구글 캘린더 옵션 창 (시험 인스턴스, 가짜 구글, 캘린더 5개)

가짜 구글 캘린더: 내 캘린더(기본, 내 것), 가족(공유, 쓰기 가능), 친구(읽기만), 회사 공지(읽기만), 대한민국 공휴일(읽기만). 친구와 가족 캘린더에는 같은 결혼식 일정(같은 iCalUID)이 있다.

- 01-settings-gcal-box-ko.png: 설정 비서 탭 구글 칸. 캘린더 주소 칸 대신 "가져오기: 내 캘린더 / 보내기: 내 캘린더" 요약과 "캘린더 고르기" 단추 (ko, 밝게)
- 02-options-ko-light.png: 구글 캘린더 옵션 창 기본 상태. 내 캘린더만 가져오기, 보내기는 내 캘린더. 읽기만 캘린더는 보내기 칸이 막혀 있다 (ko, 밝게)
- 03-options-ko-checked.png: 가족, 친구, 공휴일 가져오기를 켜고 보내기를 가족으로 바꾼 뒤
- 04-events-list-calendars.png: 바꾼 뒤 일정 탭 목록. 가져온 일정마다 캘린더 색 점과 이름(내 캘린더, 가족, 친구, 대한민국 공휴일). 결혼식은 가족 것 하나만. 페어리 일정(아침 달리기)은 가족 캘린더로 옮겨져 "구글"
- 05-events-list-calendars-dark.png: 같은 목록, 어두운 모드
- 06-calendar-month-colors.png: 달력 보기. 구글 일정 줄이 그 캘린더 색
- 07-options-narrow-360.png: 설정 창을 폭 360px 로 줄였을 때 옵션 창 (아래에서 올라오는 판, 가로 넘침 없음)
- 08-options-en-dark.png: 옵션 창 영어, 어두운 모드
- 09-options-old-token-relink.png: 예전 연결(일정 권한만, 캘린더 목록 권한 없음). 목록 대신 "캘린더 목록을 보려면 다시 연결해 줘" 안내와 다시 연결 단추, 그동안은 기본 캘린더와 직접 넣은 ID 줄로 지금처럼
- 10-settings-gcal-box-old-token.png: 예전 연결일 때 설정 구글 칸 (다시 연결 안내 한 줄)
