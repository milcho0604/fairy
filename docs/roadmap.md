# 짝꿍 진행표

기획서 [개발 단계](plan.md#개발-단계)를 실제 작업 단위로 쪼갠 체크리스트다. 하나 끝낼 때마다 체크하고, 단계가 끝나면 걸린 시간을 추정과 비교한다.

- 상태 표시: `[x]` 완료, `[ ]` 할 일, `[~]` 진행 중이거나 일부만 됨, `[-]` 보류
- 시간은 작업한 시간(대기 시간 제외)을 적는다.

## 0단계: 기술 검증

목표: 맥과 윈도우에서 어려운 세 가지(투명 창 클릭 통과, 영역 캡처, AI CLI 호출)가 되는지 확인하고, 비기능 목표를 처음 잰다. 코드는 `spike/` 에 두고, 결과만 확인하면 버리는 실험 코드다.

**준비**

- [ ] 윈도우 테스트 환경 정하기 (가상 머신, 별도 PC, CI 중)
- [x] 실험용 Electron 앱 뼈대 (`spike/`, Electron 44.5.1)

**맥**

- [~] M1 투명, 항상 위 창에 펫 표시. 창이 뜨는 것까지 확인. 손 시험 대기 (아래 "다음에 이어서 할 일" 3번)
- [ ] M2 펫 밖 클릭이 아래 앱으로 통과 (사람이 직접 확인)
- [ ] M3 펫 위에서는 클릭과 드래그가 펫으로 간다
- [x] M4 화면 기록 권한 상태 읽기. 단독 실행 시 `denied` 를 정확히 읽는다. 터미널에서 띄우면 실제로는 못 찍는데도 `granted` 로 나온다 (개발 중 함정)
- [ ] M5 화면 일부를 캡처해 PNG 로 저장 (빈 화면이 아닌지). 권한이 없어 대기. 시스템 설정에서 Electron 에 화면 녹화 권한을 주면 다시 실행
- [x] M6 claude 이미지 질문을 앱 안에서 보내고 답 받기. 첫 글자 5.0초, 전체 5.8초, 조각 27개로 실시간 표시 가능. Finder 실행처럼 PATH 가 짧아도 로그인 셸로 찾아 성공 (찾는 데 약 2초, 경로를 저장해 두면 된다)
- [ ] M7 codex 이미지 질문 (한도가 넉넉할 때)
- [x] M8 가만히 있을 때 CPU, 메모리 재기. 펫 애니메이션을 켠 채 60초 평균 CPU 0.65% (최대 0.72%), 메모리 325MB (창 1개, 프로세스 4개). CPU 목표 1% 통과, 메모리는 창 3개 목표 400MB 가 빠듯하다
- [~] M9 모니터 여러 대에서 펫 창 위치와 배율. 모니터 3대(1920x1080 배율 1 두 대, 내장 1512x982 배율 2)를 정확히 읽음. 모니터마다 창 띄우기는 1단계에서

## 다음에 이어서 할 일

2026-10-01 20시쯤 PC 를 떠나며 멈춘 자리다. 순서대로 하면 0단계 맥 검증이 끝난다.

1. **화면 기록 권한 주기**: 시스템 설정, 개인정보 보호 및 보안, 화면 및 시스템 오디오 녹화에서 **Electron** 을 켠다. 목록에 없으면 아래 2번의 캡처 명령을 한 번 실행해 요청 창을 띄운다.
2. **캡처 시험 (M5)**: `cd spike && open -n node_modules/electron/dist/Electron.app --args "$PWD" --capture-test` 실행 뒤 `spike/out/log.txt` 의 `[capture]` 줄과 `spike/out/capture.png` 를 본다. 터미널에서 `npm run capture` 로 띄우면 권한이 잘못 읽히므로 꼭 `open` 으로 띄운다.
3. **펫 손 시험 (M1~M3)**: `cd spike && open -n node_modules/electron/dist/Electron.app --args "$PWD" --pet` 로 띄우고 다섯 가지를 해 본다.
    1. 펫 주변 빈 곳 아래의 창이나 아이콘이 평소처럼 눌리는가 (M2)
    2. 펫을 클릭하면 "안녕! 클릭 잘 받았어" 말풍선이 뜨는가 (M3)
    3. 펫을 드래그하면 따라오는가 (M3)
    4. 우클릭하면 "우클릭 메뉴 자리" 말풍선이 뜨는가
    5. 다른 앱을 쓰는 동안에도 펫이 맨 위에 보이는가 (M1)
    - 기록은 `spike/out/log.txt` 의 `[pet]`, `[hover]` 줄에 남는다. 끌 때는 `pkill -f "my_friend/spike"`.
4. **윈도우 테스트 환경 정하기**: 맥 가상 머신, 별도 윈도우 PC, GitHub Actions 중 고른다. GitHub Actions 로는 빌드와 CLI 호출만 확인되고 클릭 통과는 못 본다.
5. **Codex 시험 (M7)**: 한도가 넉넉할 때 [AI CLI 검증 시나리오](tests/ai-cli.md)의 X2, X4~X8.
