# 윈도우 확인 체크리스트

맥에서는 다 돌지만 윈도우에서는 한 번도 못 돌려 본 것들이다 (D1). 윈도우 환경이 생기면 위에서부터 차례로 하고, 결과 칸에 적은 뒤 진행표(`docs/roadmap.md`)의 해당 줄을 체크한다.

## 시험 환경 (D1, 2026-10-06 정함)

- **맥미니 M4 (메모리 24GB) + 가상 머신에 윈도우 11 ARM.** 도커는 안 된다(윈도우 컨테이너는 윈도우 커널에서만 돌고, 맥 도커에는 가상화 장치 KVM 이 없다).
- 가상화 프로그램: UTM(무료, 그래픽 가속 약함), VMware Fusion(개인 무료), Parallels(유료, 가장 매끄러움). GPU 항목(L12)까지 보려면 Parallels 나 VMware 쪽이 낫다.
- 가상 머신 파일은 외장 SSD 에 둔다. APFS 로 포맷하고 USB-C 나 썬더볼트로 연결. 실행 중에는 뽑지 않는다.
- 크기: 설치 이미지 약 5~6GB(설치 뒤 지워도 됨), 가상 디스크 64GB(쓴 만큼만 차지, 실제 약 30~40GB).
- 가상 머신에 메모리 6~8GB, CPU 4개.
- 한계: ARM 윈도우라 짝꿍(x64)은 에뮬레이션으로 돈다. CPU, 메모리 수치는 실제 x64 PC 보다 나쁘게 나올 수 있다. 수치가 기준을 넘으면 x64 PC 에서 한 번 더 잰다.
- 빌드와 테스트만 보는 것은 GitHub Actions 윈도우 러너가 이미 한다(`.github/workflows/release.yml`). 여기서는 화면과 운영체제 동작만 본다.

## 준비

1. GitHub 레포 Actions 탭 → release → Run workflow. 끝나면 실행 화면 아래 Artifacts 의 `jjakkung-Windows` 를 받는다 (`jjakkung-<버전>-win-x64.exe`).
2. 가상 머신에 Node 22.18 이상, 시험할 AI CLI(claude, codex 중 하나 이상)를 설치하고 로그인한다.
3. 결과에 적을 것: 윈도우 판(설정 → 시스템 → 정보), 가상화 프로그램과 판, 화면 배율.

## 체크리스트

결과 칸: 통과, 실패(증상), 해당 없음. 실패는 화면을 찍어 둔다.
