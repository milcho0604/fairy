# 말풍선 간격과 집 복구 (#185)

## 말풍선

기존 배치는 펫 창의 위/아래 끝을 기준으로 삼아 그림의 투명 여백이 그대로 간격에 더해졌다.
그림이 바뀔 때 서 있는 몸을 그림자 없이 한 번 그려 불투명 윗선/아랫선을 재고,
캔버스 높이에 대한 비율을 메인에 전달한다. 창 크기, 꾹 눌러 확대하기에는 같은 비율을 적용한다.
걷기, 점프, GIF 프레임을 따라 다시 재지 않으므로 동작에 따라 말풍선이 출렁이지 않는다.
그림 세트는 idle, 움직이는 사진은 첫 프레임을 쓴다. 입체도 같은 모델의 서 있는 모습을 잰다.

배치, 화면 끝 보정, 다른 펫 말풍선과의 충돌 판정이 같은 기준을 쓴다.
위에 자리가 없을 때는 불투명 아랫선 아래로 띄운다. 투명 여백 안에 말풍선이 들어가도
원래 펫 캔버스를 창 안에 남겨 그림과 클릭 영역이 잘리지 않게 한다.

`BUBBLE_GAP=10`은 기존 값이며 말풍선 외곽 여백과 꼬리를 포함한다.
시험은 실제 CSS 꼬리의 회전한 끝과 캔버스 불투명 픽셀을 비교한다.
배치는 알파 24 이상, 화면 측정은 96 이상을 사용하므로 확대 시 흐린 테두리만큼 차이가 날 수 있다.

## 집 숨김/표시 경로 전수 확인

| 호출 위치 | 동작 | 해제/복구 경로 |
| --- | --- | --- |
| `index.ts` 초기화 | 저장된 `houseHidden`을 `house.stow`에 적용 | 설정/메뉴에서 `setHouseHidden(false)` → 설정 듣개 → `applyHouseStow(false)` |
| `index.ts` `applyHouseStow` | 쉬는 펫을 먼저 부르거나 문 전환 완료 후 `house.stow(on)` | 같은 함수의 `on=false`; 쉬는 중 상태 전환은 `stowStep`으로 기다림 |
| `index.ts` 2초 주기 | user/presentation 숨김이면 `house.hide()` | 두 이유가 모두 풀리면 `house.unhide()`; 집 안에서 쉬는 숨김은 여기에 포함하지 않음 |
| `play.ts` `setHiddenBy` | `hiddenBy.add/delete`의 유일한 위치; 감출 이유가 남으면 창 숨김 | 마지막 이유 삭제 후 현재 모니터 바닥에 배치하고 `showInactive` |
| `index.ts` 상점 변경 콜백 | `house.show`: 단계/모양 변경 | 숨김 이유 유지. 0단계는 제거, 같은 그림은 재배치, 다른 그림은 재생성 |
| `index.ts` 코인/물건 초기화 | `house.show`: 구매한 집 제거 | 0단계이면 정상 제거; 집 안의 펫은 `rest.houseGone`으로 부름 |
| `index.ts` 서버 물건 동기화 | `house.show`: 서버의 집 단계 반영 | 집 제거 시 `rest.houseGone`; 남아 있으면 같은 숨김 이유 적용 |
| `index.ts` 펫 `did-finish-load` | `house.show`: 다시 읽은 펫과 집 맞춤 | 저장된 구매 단계/모양과 기존 숨김 이유 유지 |
| `play.ts` `ready-to-show` | 숨김 이유가 없을 때만 최초 표시 | 숨긴 상태로 단계가 올라도 다시 띄우지 않음 |
| `play.ts` `heal` | 창 소멸/렌더러 죽음은 재생성, 내려간 창은 표시, 화면 밖은 재배치 | 모니터 변경, 2초 주기, 렌더러 죽음에서 실행; 종료 중/드래그/이동 중은 보류 |
| `play.ts` 집 `did-finish-load` | 매번 문/방 CSS 상태와 문간·침대 그림 복원 | 기존 once 듣개는 두 번째 로딩에 실행되지 않았으므로 반복 듣개로 수정 |
| `index.ts` Dock/큰 창 전체 화면 전환 | 펫과 집 모두 `reassertSpaces` | 집도 항상 위/모든 데스크톱 설정을 다시 적용하고 `heal`; 숨김 이유 유지 |

`stowed`와 `pet`의 추가/삭제는 짝이 있다. 기존에 보고된 모든 집 실종 현상을 한 원인으로
재현한 것은 아니다. 확인된 누락은 집 렌더러 재로딩의 상태 복원과 Dock 전환 후 집의 창 설정
재적용이다. 주기 복구는 숨김 이유부터 맞춘 뒤 실행해 숨겨야 할 집을 먼저 복원하지 않게 했다.

생산 코드에는 집을 투명하게 만드는 `setOpacity` 호출이 없다. 시험의 불투명도 0은
`focus.ts`의 `JJ_NO_FOCUS=1` 정책이며 복구 과정에서도 유지해야 한다.

## 실행

```bash
npm run check
npm run build
OUT=/tmp/fairy-185 LANG_UNDER_TEST=ko node scripts/dev/bubble-house.mjs
OUT=/tmp/fairy-185 LANG_UNDER_TEST=en node scripts/dev/bubble-house.mjs
```

단위 시험은 `src/shared/bubble.test.ts`, `house.test.ts`, `house-stow.test.ts`에 있다.
화면 시험은 빈 `JJ_USER_DATA`, 임시 HOME, `JJ_NO_FOCUS=1`로 앱을 직접 띄운다.
입력은 CDP만 쓰고 기본 펫만 촬영하며 프로세스와 임시 데이터를 마지막에 지운다.
`OUT`에는 언어별 측정 JSON, 판정 목록, 기본 펫 PNG, 앱 로그를 남긴다.

- 기본 2D/3D 펫, 투명 여백이 큰 사진, 가져온 2D 그림 세트 × 배율 0.5/1/1.5/2 × 위/화면 위 끝/화면 옆 끝
- 실제 꼬리 간격, 꼬리 가로 정렬, 펫 캔버스 잘림, 걷기/점프 프레임에서 기준 고정
- 펫 user/presentation 숨김 복귀, 두 집 숨김 이유의 독립 해제, 숨긴 채 단계 변경
- 내려간 창, 화면 밖 창, 없어진 창, 집/펫 렌더러 재로딩, 문간 그림과 문 상태 복원
- 큰 창 열기/숨기기 및 전체 화면 이벤트 뒤 집 창 설정 재적용, 실제 Dock 표시 호출 0
- 들어가는 중/집 안/나오는 중 펫 숨김과 다시 부르기, 잠자기/깨우기 알림
- 집 안에서 종료/재시작, 사용자가 숨긴 집의 재시작 후 유지와 다시 보이기

모니터 제거는 외부 모니터를 조작하지 않고 화면 밖에 남은 집 창을 주입한다.
전체 화면과 잠자기는 이벤트를 주입한다. 실제 디스플레이 연결/분리, OS 잠자기,
화면 공유, 실제 Dock 앱 종류 변경에 의한 macOS 동작은 이 자동 시험의 범위 밖이다.
