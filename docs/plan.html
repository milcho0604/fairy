문서 버전 0.1.1 (2026-10-01). 변경 이력은 CHANGELOG에 남긴다.

화면 위를 돌아다니는 펫이 할 일, 일정, 메모를 같이 챙기고, 내 컴퓨터에 설치된 AI(Claude, Codex)와 연결돼 "같이 보기"로 화면을 보며 대화하는 데스크톱 앱이다. 맥과 윈도우를 동시에 낸다.

개요

일하는 시간을 덜 외롭고 더 재미있게 만드는 것이 목표다. 펫은 귀여운 놀이 상대이면서, 할 일과 일정을 챙기고 AI와 이어 주는 비서 역할을 한다.

대상 사용자

  • 하루 대부분을 컴퓨터 앞에서 보내는 직장인과 학생
  • Claude Code, Codex 같은 로컬 AI를 이미 쓰는 개발자와 기획자
  • 할 일 앱을 깔아도 금방 안 보게 되는 사람

핵심 가치 세 가지

  1. 눈에 보이는 동기: 할 일을 끝내면 코인이 생기고, 펫이 밥을 먹고 집이 커진다. 해야 할 일이 펫을 돌보는 일로 바뀐다.
  2. AI가 화면 옆에 산다: 창을 바꾸지 않고 펫에게 말을 걸거나, 화면 일부를 잘라 "같이 보기"로 물어본다. 내가 이미 쓰는 Claude, Codex를 그대로 쓰므로 따로 API 키가 필요 없다.
  3. 내 펫: 사진 한 장으로 내 반려동물이나 좋아하는 캐릭터가 펫이 된다. 먹이와 집도 꾸밀 수 있다.

만들지 않을 것 (처음 범위 밖)

  • 펫끼리 만나는 온라인 기능, 계정과 서버. 모든 데이터는 내 컴퓨터에 저장한다.
  • 자체 AI 모델. 이미 설치된 AI를 연결만 한다.

하루 사용 흐름

펫은 하루 내내 화면 구석에 있고, 필요할 때만 다가온다.

  1. 출근: 컴퓨터를 켜면 펫이 화면 아래로 걸어 나온다. 말풍선으로 오늘 일정 2건과 마감이 오늘인 할 일 3개를 알려준다.
  2. 오전 작업: 펫을 클릭해 "회의록 정리"를 할 일로 넣는다. 집중 타이머를 켜면 펫은 옆에서 조용히 잠든다.
  3. 막혔을 때: 에러 화면을 "같이 보기"로 드래그해서 자른다. 채팅창이 열리고 캡처가 첨부된 채 Claude가 답한다. 답을 메모로 저장하거나 할 일로 바꾼다.
  4. 점심: 오전에 끝낸 할 일로 받은 코인으로 먹이를 사서 준다. 공을 던지면 펫이 화면을 뛰어다닌다.
  5. 오후 회의: 화면 공유가 시작되면 펫이 알아서 숨는다. 회의가 끝나면 다시 나온다.
  6. 지칠 때: 2시간 넘게 쉬지 않았으면 펫이 산책을 조른다. 산책을 누르면 펫이 화면 바닥을 따라 걸으며 스트레칭을 권한다.
  7. 퇴근: 오늘 끝낸 일과 받은 코인을 보여 주고, 내일로 넘길 할 일을 물어본다. 펫은 집으로 들어가 잔다.

게임 규칙

코인은 일을 끝낼 때만 생기고, 펫을 돌보는 데만 쓴다. 펫은 방치해도 아프거나 떠나지 않는다. 죄책감이 아니라 보상으로 움직이게 하려는 것이다.

구분 항목 초안 값
획득 할 일 1개 완료 10코인 (하루 최대 20개까지)
획득 집중 타이머 1회 5코인
획득 마감 전 완료 +5코인
획득 산책, 휴식 권유 따르기 3코인
소비 기본 먹이 5코인
소비 커스텀 먹이 만들기 50코인 (한 번)
소비 장난감 30~100코인
소비 집 업그레이드 단계별 200, 500, 1,000코인

펫 상태 수치 (0~100)

  • 배부름: 시간이 지나면 천천히 줄고, 먹이로 채운다. 낮아도 배고픈 표정만 짓는다.
  • 기분: 쓰다듬기, 놀이, 할 일 완료로 오른다.
  • 친밀도: 계속 쌓이기만 하고 줄지 않는다. 단계마다 새 동작이나 대사가 열린다.

코인 값은 초안이다. 할 일을 잘게 쪼개 코인을 버는 것을 막으려고 하루 상한을 두었다.

시스템 구조

앱 본체 하나가 모든 연결을 맡는다. 화면 창들은 본체와만 이야기하고, 펫 MCP 서버가 있어서 Claude Code 같은 외부 도구도 펫에 할 일을 넣을 수 있다.

기술 스택

Electron + TypeScript로 간다. 펫 앱의 핵심인 "펫이 아닌 투명한 곳만 클릭 통과"를 맥과 윈도우 모두에서 공식 API로 지원하는 후보는 Electron 하나뿐이었다. 대가는 설치 파일 80MB 이상과 더 큰 메모리다. 2순위는 Tauri v2다.

후보 최신 버전 (2026-10-01 확인) 투명 영역 클릭 통과 MCP SDK 언어 판단
Electron 44.5.1 setIgnoreMouseEvents(true, {forward: true})를 맥, 윈도우에서 공식 지원 TypeScript (Tier 1) 채택
Tauri v2 2.12.0 창 전체 단위만. 투명 영역만 통과하려면 커서 위치를 계속 검사하는 우회 코드 필요 Rust (Tier 1) 2순위
Wails v2.14.0, v3는 베타 v3에 있으나 이벤트 전달은 확인 못 함 Go (Tier 1) 베타라 제외
Electrobun v2.0.2 웹뷰 단위 통과만 확인 TypeScript 제외
Flutter 3.x 플러그인(window_manager)에 의존 공식 Dart SDK 없음 제외
Avalonia 11~12 문서에 미지원으로 명시 C# (Tier 1) 제외
Qt 6.10 창 전체만 통과 공식 C++ SDK 없음 제외

Electron을 고른 근거

  1. 클릭 통과가 공식 기능이다. Tauri는 같은 기능 요청(#2090)에 16ms마다 픽셀을 검사하는 우회책만 있다. 2026-08에는 데스크톱 펫 개발사가 클릭 통과를 켜고 끌 때 윈도우 10 화면이 검게 변하는 버그(#15947)를 올렸고 아직 열려 있다.
  2. 두 OS가 같은 브라우저 엔진을 쓴다. Electron은 Chromium을 함께 묶는다. 배경 제거 모델(ONNX, WASM), 캡처, 애니메이션을 한 번만 검증하면 된다. Tauri는 맥 WKWebView와 윈도우 WebView2를 따로 확인해야 하고, 맥에서 DMG로 묶으면 투명 창이 흰 창이 되는 버그(#13415)도 있다.
  3. 필요한 것이 다 들어 있다. 영역 캡처(desktopCapturer), 맥 화면 기록 권한 확인, CLI 실행(Node child_process), 트레이, 전역 단축키가 모두 기본 기능이다.
  4. MCP 서버를 같은 언어로 넣는다. MCP 공식 TypeScript SDK를 앱 본체에 그대로 올린다.
  5. 실제 펫 앱이 있다. Electron으로 만든 데스크톱 펫(Zpet, Clawd 등)이 같은 구조(투명, 항상 위, 펫 밖 클릭 통과)로 돌아간다.

대가와 대응

  • 크기: 비교 글 기준 Hello World 앱이 Electron 85MB, Tauri 3.2MB다(출처). 펫 앱 용도에서는 감수한다.
  • 윈도우 이벤트 전달 버그(#30808, #48035)가 열려 있다. 0단계에서 윈도우 10과 11 실기기로 확인하고, 안 되면 커서 위치 검사 방식으로 바꾼다.
  • 맥 여러 모니터: "디스플레이마다 별도 Spaces" 설정에서는 창이 한 화면에 묶인다. 모니터마다 투명 창을 하나씩 두는 구조로 설계한다.

설치와 배포

맥은 dmg, 윈도우는 exe 설치 파일로 내고, GitHub Releases에 올려 자동 업데이트한다. npm은 개발자가 아닌 사용자가 쓰지 않으므로 제외한다.

배포 순서

  1. 베타는 서명 없이 지인에게 나눈다. 설치 안내문에 경고 창 넘기는 법을 그림으로 넣는다.
  2. 공개 전에 맥 공증부터 붙인다. 맥은 경고를 넘기는 과정이 더 길어 이탈이 크다.
  3. 개발자 사용자를 위해 Homebrew cask, winget 등록은 이후에 검토한다.

맥 App Store와 Microsoft Store는 처음 범위에서 뺀다. 항상 위 투명 창, 화면 캡처, 외부 CLI 실행이 스토어 샌드박스 제약에 걸릴 가능성이 커서 따로 확인이 필요하다.

개발 단계

기능보다 먼저 "두 OS에서 어려운 세 가지가 되는가"를 확인한다. 여기서 막히면 기술 스택을 바꾼다.

  1. 0단계, 기술 검증: 투명 창 클릭 통과, 영역 캡처, claude/codex 실행과 답변 받기.
    • 완료 기준: 맥과 윈도우 둘 다에서 세 가지가 동작한다.
  2. 1단계, 펫: 화면 표시, 드래그, 크기 조절, 자율 행동, 사진으로 펫 만들기, 방해 금지.
    • 완료 기준: 아무 사진 10장을 넣어 보고 8장 이상이 자연스럽게 나온다. 하루 켜 둬도 일을 방해하지 않는다.
  3. 2단계, 할 일과 코인: 할 일, 메모, 빠른 입력, 코인, 밥 주기.
    • 완료 기준: 내가 일주일 동안 실제 할 일 앱으로 쓴다.
  4. 3단계, AI: 로컬 AI 감지, 채팅, 같이 보기, 보내기 전 확인.
    • 완료 기준: 캡처부터 답변 첫 글자까지 기다리는 시간을 재서 남긴다.
  5. 4단계, MVP 베타: 설치 파일, 첫 실행 안내, 트레이, 자동 실행. 지인 5~10명에게 배포한다.
    • 완료 기준: 두 OS에서 설치 파일만으로 설치하고 실행된다.
  6. 5단계, v1: 공놀이, 산책, 일정과 알림, 집중 타이머, 상점, 집, 커스텀 먹이, 펫 MCP 서버, 자동 업데이트.
  7. 6단계, v2: 구글 캘린더, 외부 MCP, 여러 마리, 펫 공유, 업적, 백업, 다국어.

리스크와 정할 것

가장 큰 위험은 투명 창 클릭 통과가 맥과 윈도우에서 다르게 동작하는 것이다. 0단계에서 가장 먼저 확인한다.

위험 영향 대응
클릭 통과 동작이 OS마다 다름 펫 뒤 앱을 눌러도 안 눌리거나 펫을 못 잡는다 0단계에서 두 OS 실측. 안 되면 스택 교체
맥 화면 기록 권한 권한이 없으면 같이 보기가 빈 화면을 찍는다 첫 실행 안내에서 설정 화면으로 바로 보내기
회사 보안 프로그램 캡처나 항상 위 창을 막을 수 있다 기능별로 꺼도 나머지가 돌게 만든다
CLI 출력 형식 변경 claude, codex 업데이트로 연동이 깨진다 AI마다 어댑터를 따로 두고 버전을 기록
민감한 화면 전송 회사 자료가 AI로 나간다 보내기 전 미리보기와 확인을 기본값으로
서명 없는 설치 파일 두 OS 모두 경고 창이 떠서 설치를 포기한다 베타는 설치 안내문으로, 공개 전 서명
배경 제거 품질 털이나 어두운 배경에서 지저분해진다 수동 다듬기 도구(지우개, 복원) 제공
맥에서만 개발 윈도우 문제를 늦게 발견한다 윈도우 테스트 환경을 0단계 전에 마련
