# 짝꿍 설치 안내 (베타)

짝꿍은 아직 애플과 마이크로소프트의 개발자 서명을 받지 않았다(D4). 그래서 처음 열 때 한 번 경고가 뜬다. 아래대로 한 번만 넘기면 그다음부터는 그냥 열린다.

## 맥

맥 OS 15(Sequoia) 이상 기준이다. 이전 판에서는 앱을 우클릭해 "열기"를 눌러도 된다.

1. 받을 파일 고르기
    - 애플 실리콘(M1 이후): `jjakkung-<버전>-mac-arm64.dmg`
    - 인텔: `jjakkung-<버전>-mac-x64.dmg`
    - 모르겠으면 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여 → "칩"이 Apple M 으로 시작하면 애플 실리콘이다.
2. dmg 를 열고 **Jjakkung** 을 응용 프로그램 폴더로 끌어 넣는다.
3. 응용 프로그램 폴더에서 Jjakkung 을 연다. 확인할 수 없어 열지 않았다는 창이 뜨면 "완료"를 누른다. (휴지통으로 옮기지 않는다.)
4. 시스템 설정 → **개인정보 보호 및 보안** → 아래쪽 "보안" 칸에서 "Mac을 보호하기 위해 ‘Jjakkung’을(를) 차단했습니다." 옆의 **그래도 열기** 를 누른다. 맥 암호를 넣는다.
5. 다시 뜨는 창에서 **그래도 열기** 를 누르면 화면에 펫이 나온다.

그래도 열리지 않으면 터미널에서 아래 한 줄을 실행한 뒤 다시 연다. 인터넷에서 받은 파일 표시를 지우는 명령이다.

```bash
xattr -dr com.apple.quarantine /Applications/Jjakkung.app
```

### 같이 보기 권한 (화면 기록)

"같이 보기"는 고른 화면 영역을 찍어 AI 에게 보여 준다. 처음 쓸 때 맥이 화면 기록 권한을 묻는다.

1. 짝꿍이 "화면 기록 권한이 필요해" 안내를 띄우면 **설정 열기** 를 누른다.
2. 시스템 설정 → 개인정보 보호 및 보안 → **화면 및 시스템 오디오 녹음** 에서 Jjakkung 을 켠다.
3. 맥이 "종료 후 다시 열기"를 물으면 그렇게 한다. 권한은 앱을 다시 켜야 적용된다.

찍은 화면은 디스크에 남기지 않고, 고른 AI 에게만 보낸다. 짝꿍 자체는 어떤 서버로도 보내지 않는다.

## 윈도우

1. `jjakkung-<버전>-win-x64.exe` 를 받아 실행한다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 **추가 정보** → **실행** 을 누른다.
3. 관리자 권한 없이 바로 설치되고 펫이 나온다. 시작 메뉴에는 "짝꿍"으로 보인다.

같이 보기는 윈도우에서 따로 권한을 묻지 않는다.

## AI 연결

짝꿍은 AI 를 직접 갖고 있지 않고, 이 컴퓨터에 설치해 로그인해 둔 AI 프로그램(CLI)을 부른다. 하나 이상 있어야 대화가 된다.

- Claude Code (`claude`), Codex (`codex`), Cursor (`cursor-agent`), Gemini (`gemini`) 중 하나
- 설치와 로그인은 각 프로그램 안내를 따른다. 짝꿍 채팅 창의 AI 고르기에서 "설치됨, 로그인됨"으로 보이면 된다.
- 위 목록에 없는 CLI 도 채팅 창에서 직접 추가할 수 있다.

## 지우기

- 맥: 메뉴 막대의 짝꿍 아이콘 → 끝내기, 응용 프로그램 폴더에서 Jjakkung 을 휴지통으로.
- 윈도우: 설정 → 앱 → 설치된 앱 → 짝꿍 → 제거.
- 할 일, 코인, 설정, 사진 펫은 지워도 남는다(다시 설치하면 이어서 쓴다). 완전히 지우려면 아래 폴더도 지운다.
    - 맥: `~/Library/Application Support/jjakkung`
    - 윈도우: `%APPDATA%\jjakkung`

## 의견 보내기

메뉴 막대(윈도우는 작업 표시줄 오른쪽 아래)의 짝꿍 아이콘 → **의견 보내기**. "내 기록" 칸의 **기록 복사** 를 눌러 의견과 같이 붙여 보내 주면 된다. 복사한 글에는 날짜와 숫자만 들어 있다.
