개인정보처리방침

페어리는 서버 없이 내 컴퓨터에서 도는 데스크톱 앱이에요. 무엇을 어디에 두고, 무엇이 언제 어디로 나가는지 있는 그대로 적었어요.

시행일 2026년 10월 12일

이 방침이 다루는 것

데스크톱 앱 페어리(영문 이름 fairy)와 이 사이트 fairy.moilga.com에 적용돼요. 페어리는 milcho0604가 만드는 MIT 라이선스 오픈 소스 앱이에요. 계정이 없고 페어리 서버도 없어서, 만든 사람은 여러분의 데이터를 받지도 보지도 않아요.

내 컴퓨터에 저장하는 것

아래는 모두 이 컴퓨터의 페어리 데이터 폴더에만 저장돼요.

  • 할 일, 메모, 일정, 일기, 코인, 페어리 상태와 페어리가 기억하는 것, 설정 (SQLite 저장 파일과 설정 파일)
  • 채팅 창의 최근 대화 40개. 붙인 그림은 저장하지 않아요
  • 구글 캘린더 연결 토큰과, 넣었다면 Hugging Face 토큰. 나만 읽을 수 있는 파일(권한 0600)에 두고, 운영체제 열쇠(맥 키체인, 윈도우 DPAPI, 리눅스 libsecret 등)를 쓸 수 있으면 암호화해요
  • 진단 기록(logs 폴더, 합쳐서 2MB 이하). 질문, 답, 할 일과 일정 제목은 남기지 않고 파일 경로 속 사용자 이름은 가려요
  • 받아 둔 AI 모델과 도구, 모델 목록 사본
  • "같이 보기"로 찍은 화면은 디스크에 저장하지 않아요

데이터 폴더 위치

  • macOS ~/Library/Application Support/fairy
  • Windows %APPDATA%\fairy
  • Linux ~/.config/fairy

정보를 쓰는 곳

저장한 정보는 알림, 페어리의 말과 행동, 고른 AI와의 대화처럼 여러분이 쓰는 기능을 이 컴퓨터에서 돌리는 데만 써요. 광고, 분석, 프로필 만들기에는 쓰지 않아요.

컴퓨터 밖으로 나가는 것

그 기능을 직접 쓸 때만 나가요. 페어리 서버를 거치지 않고 이 컴퓨터에서 바로 그곳으로 가요.

  • AI 대화, 같이 보기, 메모와 일기 다듬기: 질문, 고른 화면이나 그림, 그 메모나 일기 글을 여러분이 고른 AI 프로그램(Claude Code, Codex, Cursor, Gemini CLI, 직접 추가한 프로그램)에 넘겨요. 그 프로그램이 자기 회사(Anthropic, OpenAI, Cursor, Google 등)로 보내고, 거기서부터는 그 회사의 약관과 개인정보 정책을 따라요. 페어리 이름과 성격도 같이 가요. "내 할 일 같이 보내기"나 "페어리 도구 쓰기"(둘 다 처음에는 꺼져 있어요)를 켜면 할 일과 일정도 갈 수 있어요. 구글 캘린더에서 읽어 온 일정은 "AI가 구글 일정도 볼 수 있게"까지 켜야 가요. 무료 AI(이 컴퓨터에서 도는 모델)를 고르면 아무것도 나가지 않아요.
  • AI 일러스트 (무료 서버): 고른 사진과 바라는 점을 Hugging Face의 무료 그림 서버(다른 사람이 운영하는 Space)로 보내요. Hugging Face 토큰을 넣었다면 그 서버에만 같이 보내요.
  • 구글 캘린더 연결: 아래 "구글 캘린더" 항목에 따로 적었어요.
  • 캘린더 가져오기: 여러분이 넣은 .ics 주소에서 일정을 받아 오기만 해요.
  • 업데이트 확인과 자동 업데이트, 모델 목록, 페어리 갤러리: GitHub의 공개 저장소 milcho0604/fairy-releases에서 받아요. 앱 이름과 버전 말고는 알리지 않아요.
  • 모델과 도구 받기: 무료 AI나 배경 지우기 같은 기능을 처음 쓸 때 GitHub, Hugging Face, npm 저장소, jsDelivr, unpkg에서 파일을 받아요. 받기만 하고 보내는 것은 없어요.
  • 어느 곳이든 연결하면 그 서버는 여러분의 IP 주소 같은 접속 정보를 보게 돼요.
  • 사용 통계, 광고, 오류 자동 보고는 없어요. 진단 기록도 저절로 나가지 않아요. 의견을 보낼 때 여러분이 직접 복사하거나 저장해서 붙일 때만 나가요.

구글 캘린더 (구글 사용자 데이터)

설정 → 비서 → "구글 캘린더"에서 구글 계정을 연결하면 페어리에서 넣은 일정을 여러분의 구글 캘린더에도 넣고, 고른 캘린더에 원래 있던 일정을 페어리에 보여 줘요. 연결은 선택이고, 연결하지 않으면 페어리는 구글 API를 쓰지 않아요.

  • 요청하는 권한: https://www.googleapis.com/auth/calendar.events 하나뿐이에요. 다른 구글 권한은 요청하지 않아요.
  • 하는 일: 페어리에서 넣은 일정을 여러분이 고른 캘린더(비워 두면 기본 캘린더)에 넣고, 페어리에서 고치거나 지우면 구글에서도 고치고 지워요. 보낼 캘린더를 바꾸면 이미 보낸 일정을 새 캘린더로 옮겨요. 고치고 지우는 것은 페어리가 직접 넣은 일정(구글 일정 id를 적어 둔 것)뿐이에요. "구글 캘린더 일정 가져오기"를 켜 두면(연결할 때 켜지고 따로 끌 수 있어요) 고른 캘린더의 지난 7일부터 앞으로 60일까지 일정을 15분마다 읽어 와 페어리 일정 목록과 달력에 "구글에서" 표식을 달아 보이고 알려 줘요. 읽어 온 일정은 페어리에서 고치거나 지우지 않아요(구글로 쓰지 않아요).
  • 보내는 것: 일정 제목, 시작과 끝 시각, 이 컴퓨터의 시간대, 팝업 알림 시각이에요. 메모와 할 일은 보내지 않고, .ics로 가져온 일정도 구글로 보내지 않아요.
  • 읽는 것: 가져오기를 켰을 때 고른 캘린더 하나의 일정에서 제목, 시작과 끝 시각(종일 여부), 일정 식별자(id, iCalUID), 상태만 읽어요. 설명, 장소, 참석자, 첨부, 다른 캘린더, 캘린더 목록과 설정은 읽지 않아요. 읽은 것은 이 컴퓨터의 저장 파일에만 두고, 가져오기를 끄거나 캘린더를 바꾸거나 연결을 끊으면 지워요. 기본으로는 AI 대화, "오늘 뭐부터", 계획 다듬기, 페어리 도구를 포함해 어디로도 보내지 않아요. 설정의 "AI가 구글 일정도 볼 수 있게"(처음에는 꺼져 있어요)를 여러분이 켠 경우에만, 그 기능을 쓸 때 읽어 온 일정의 제목과 시각을 여러분이 고른 AI로 보내요. 클라우드 AI면 그 회사로 가고, 무료 AI(이 컴퓨터에서 도는 모델)면 이 컴퓨터 밖으로 나가지 않아요. 끄면 바로 다시 보내지 않아요. 페어리가 넣은 일정에는 구글이 돌려주는 식별자만 적어 둬요.
  • 연결 방식: 구글의 설치 앱용 OAuth(PKCE, 이 컴퓨터의 127.0.0.1 루프백 주소)로 기본 브라우저에서 허락을 받아요. 구글 비밀번호는 페어리가 보지 않아요.
  • 보관: 오래 쓰는 토큰(refresh token)만 데이터 폴더의 google-token.json(권한 0600, 운영체제 열쇠로 암호화할 수 있으면 암호화)에 둬요. 잠깐 쓰는 토큰(access token)은 메모리에만 있어요. 토큰은 백업, 설정, 진단 기록에 넣지 않아요. 페어리 서버가 없으니 이 컴퓨터와 구글 사이에서만 오가요.
  • 연결 끊기: 설정의 "연결 끊기"를 누르면 이 컴퓨터의 토큰을 지우고 구글에서도 권한을 거둬요(oauth2.googleapis.com/revoke). 이미 보낸 일정은 구글 캘린더에 그대로 남으니, 필요하면 구글 캘린더에서 지워 주세요. 구글 계정 → 보안 → 서드 파티 연결에서 거둬도 돼요.

Limited Use

페어리가 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 일은 Limited Use 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.

fairy’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • 구글 사용자 데이터는 일정을 넣고 고치고 지우고, 구글 일정을 페어리에서 보여 주고 알려 주는 이 기능, 그리고 여러분이 켠 경우에만 고른 AI가 여러분의 일정을 보고 돕는 기능에만 써요.
  • 팔지 않아요. 여러분이 "AI가 구글 일정도 볼 수 있게"를 켜고 고른 AI로 보내는 것 말고는 다른 사람에게 넘기지 않아요. 만든 사람에게도 오지 않아서 사람이 읽을 일이 없어요.
  • 광고(맞춤 광고, 리타기팅 포함)나 신용 평가, 대출 판단에 쓰지 않아요.
  • AI나 머신러닝 모델을 만들거나 개선하거나 학습시키는 데 쓰지 않아요.

나누는 곳

만든 사람에게 오는 데이터는 없어요. 개인정보를 팔거나 빌려주지 않고, 위 "컴퓨터 밖으로 나가는 것"에 적은 곳, 곧 여러분이 그 기능을 쓸 때 고른 곳 말고는 보내지 않아요.

보관 기간과 지우기

이 컴퓨터의 데이터는 여러분이 지울 때까지 남아요. 만든 사람이 가진 사본은 없어요.

  • 할 일, 메모, 일정은 앱에서 지울 수 있어요.
  • 설정 → 데이터 → "AI 기록 지우기"는 Claude Code와 Codex가 페어리 전용 폴더에 남긴 대화 기록을 지워요. 그 AI 회사 쪽에 남은 기록은 그 회사가 정한 방법으로 지워요.
  • 구글 캘린더는 위의 "연결 끊기"로 토큰을 지우고 권한을 거둬요.
  • 진단 기록은 1MB가 넘으면 오래된 파일을 지우며 돌려서, 합쳐 2MB를 넘지 않아요.
  • 앱을 지워도 데이터 폴더는 남아요(다시 설치하면 이어서 써요). 모두 지우려면 앱을 지운 뒤 위의 데이터 폴더를 지워요.

이 사이트

쿠키, 방문 분석, 광고를 쓰지 않아요. 브라우저에는 고른 언어(localStorage)와 15분 동안의 최신 버전 정보(sessionStorage)만 저장해요. 최신 버전을 알려고 브라우저가 GitHub API에 묻고, 글꼴은 Google Fonts에서 받아요. 사이트는 Vercel에서 호스팅해요. 이곳들은 요청을 받을 때 IP 주소 같은 접속 정보를 보게 돼요.

어린이

페어리는 만 13세 미만 어린이를 대상으로 하지 않아요. 만든 사람은 누구의 개인정보도 받지 않으니 어린이의 개인정보도 모으지 않아요.
