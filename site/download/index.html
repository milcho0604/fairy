페어리 받기

내 컴퓨터에 맞는 파일을 골라 받고, 처음 한 번만 경고를 넘기면 돼요.

설치 파일

컴퓨터파일크기받기

맥에 설치하기

  1. 받을 파일 고르기. Apple 칩(M1 이후)은 …-mac-arm64.dmg, Intel은 …-mac-x64.dmg
  2. dmg를 열고 fairy를 응용 프로그램 폴더로 끌어 넣어요
  3. 응용 프로그램 폴더에서 열어요. 확인할 수 없다는 창이 뜨면 완료 (휴지통으로 옮기지 않아요)
  4. 시스템 설정 → 개인정보 보호 및 보안 → "보안" 칸의 그래도 열기, 맥 암호 입력
  5. 다시 뜨는 창에서 그래도 열기. 화면에 페어리가 나와요

그래도 안 열리면 터미널에서 이 한 줄을 실행하고 다시 열어요.

xattr -dr com.apple.quarantine /Applications/fairy.app

"같이 보기"를 처음 쓸 때는 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 fairy를 켜고 앱을 다시 켜요.

윈도우에 설치하기

  1. …-win-x64.exe를 받아 실행해요
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행
  3. 관리자 권한 없이 바로 설치되고 페어리가 나와요. 시작 메뉴에서도 페어리를 찾을 수 있어요

서명이 없는 새 앱이라 SmartScreen이 띄우는 창이에요. 추가 정보를 누르면 보이는 실행을 눌러요. 관리자 권한 없이 바로 설치되고 페어리가 나와요.

회사 컴퓨터에서 "실행" 단추 없이 막힌다면 관리자가 막아 둔 거라, 서명한 판이 나올 때까지는 설치할 수 없어요.

리눅스 (시험판)

  1. tar.xz: tar xJf로 풀어서 안의 fairy를 실행해요
  2. AppImage: chmod +x로 실행 권한을 주고 실행해요. 배포판에 따라 libfuse2가 필요해요
  3. 자동 업데이트는 없어요. 새 버전이 나오면 페어리가 릴리스 페이지를 열어 줘요

AI 연결 (선택)

이 컴퓨터에 Claude Code(claude), Codex(codex), Cursor(cursor-agent), Gemini(gemini) 중 하나를 설치하고 로그인해 두면 채팅 창에서 "설치됨, 로그인됨"으로 보여요. 없으면 채팅 창에서 "무료 AI"를 골라 받으면 돼요.

필요한 것과 크기

맥
macOS 12(Monterey) 이상. Apple 칩(M1 이후)과 Intel 둘 다
윈도우
Windows 10 이상, 64비트(x64). ARM 윈도우는 아직 지원하지 않아요
리눅스 (시험판)
x64. 데스크톱 환경(X11 또는 Wayland)과 투명 창이 되는 컴포지터
설치 파일
리눅스: tar.xz 약 89MB, AppImage 약 101MB. 맥과 윈도우는 아직 재지 않았어요. 릴리스가 열리면 단추 옆에 진짜 크기가 보여요
디스크
앱 약 310MB (리눅스 0.1.0 풀린 크기 기준)
AI 대화
Claude Code, Codex, Cursor, Gemini CLI 중 하나, 또는 무료 AI 모델(Qwen3 1.7B 약 940MB, 0.6B 약 400MB). 없어도 페어리, 할 일, 메모, 일정은 다 돼요
